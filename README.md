# catati/dev

Catati development environment setup, tracked in Git.

- [claude-cloud/](claude-cloud/README.md): the shared Claude Code cloud environment (claude.ai/code).

## Change process

1. Change the files here in a PR.
2. After merge, paste the changed values into the claude.ai/code environment form by hand. The UI has no API, so the form is the source a session uses.
3. Start a new cloud session and check it (see each folder's README).
